# Backend (Spring Boot)

This folder should contain a Spring Boot project.

Recommended quick start:
1. Visit https://start.spring.io and generate a project with:
   - Project: Maven
   - Language: Java
   - Spring Boot: latest stable
   - Dependencies: Spring Web, Spring Data JPA, H2 (or PostgreSQL), Spring Security (optional)
2. Unpack into this `backend/` folder.
3. Add Dockerfile for containerization and configure `application.properties` for DB.

I can create a basic `Dockerfile` and `pom.xml` placeholder if you want.
